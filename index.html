Data Analytics & Machine Learning · R
Chasing Ghosts
A self-directed project applying machine learning in R to detect credit card fraud in a real, anonymized dataset of 284,807 European transactions. With fraud making up only 0.17% of all cases, the central challenge was teaching a model to find the near-invisible. Built logistic regression and random forest models, used SMOTE for class imbalance, and translated the results into a real business cost framework.
